# Groups — Chapter 7: Permutations

> [!abstract] Overview
> Permutations of $\{1,\dots,n\}$ written as cycles. Every permutation is a product of disjoint cycles, essentially uniquely, which gives its cycle type and its order. Transpositions generate $S_n$, and even adjacent transpositions $(i\ i{+}1)$ suffice. The parity of the number of transpositions is well defined, giving the sign homomorphism and the alternating group $A_n$ (generated by $3$-cycles); two permutations are conjugate exactly when they have the same cycle type.
> Prerequisites: [[Groups - Chapter 1 Examples and Definitions]] ($\operatorname{Sym}(X)$, $S_n$); [[Groups - Chapter 3 Group Actions]] (orbits; conjugation).

## 7.1 Permutations and cycles

### Recall — Permutations and Sym(X)

- A **permutation** of a set $X$ is a bijection $X\to X$.
- $\operatorname{Sym}(X)$ is the group of all such permutations ([[Groups - Chapter 1 Examples and Definitions#Definition 1.14 — The groups $S_n$|Definition 1.14]]); e.g. for $X=\{1,2,3\}$, $\operatorname{Sym}(X)=S_3$.

*Two permutations of $\{1,2,3\}$, $\sigma$ ($1\mapsto3$, $2\mapsto1$, $3\mapsto2$) and $\tau$ ($1\leftrightarrow2$); the third map sends both $2$ and $3$ to $2$, so it is not a permutation.*

The group operation is composition of functions. For $\tau\circ\sigma$ (first $\sigma$, then $\tau$):
$$1\overset\sigma\longmapsto3\overset\tau\longmapsto3,\qquad2\overset\sigma\longmapsto1\overset\tau\longmapsto2,\qquad3\overset\sigma\longmapsto2\overset\tau\longmapsto1.$$

### Definition 7.1 — k-cycle

Any list of $k$ distinct elements $a_1,\dots,a_k\in\{1,\dots,n\}$ defines a **$k$-cycle** $\sigma=(a_1\,a_2\,\cdots\,a_k)\in S_n$ as follows:
$$\sigma(b)=\begin{cases}a_{i+1}&\text{if }b=a_i\ (i<k),\\a_1&\text{if }b=a_k,\\b&\text{otherwise.}\end{cases}$$
E.g. above, $\sigma=(1\,3\,2)=(3\,2\,1)=(2\,1\,3)$ (cyclic symmetry).

**Remark.** $(a_1\,a_2\,\cdots\,a_k)=(a_2\,\cdots\,a_k\,a_1)$.

**Remember:** when multiplying cycles, keep track of members "from the right". E.g. from above, $(1\,2)(1\,3\,2)$ sends $1\mapsto3$, $2\mapsto2$, $3\mapsto1$, so
$$(1\,2)(1\,3\,2)=(1\,3).$$
**Exercise:** check that $(1\,4\,3\,2)(2\,4\,3)=(1\,4\,2\,3)$.

> [!note] Explanation
> "From the right" means: to find where $b$ goes, apply the right-hand cycle first, then the left-hand one. For the exercise, $1$ is fixed by $(2\,4\,3)$ and then goes to $4$; $4\to3\to2$; $2\to4\to3$; $3\to2\to1$. So $1\mapsto4\mapsto2\mapsto3\mapsto1$, which is $(1\,4\,2\,3)$.

### Definition 7.2 — Disjoint cycles

Cycles $(a_1\,\cdots\,a_k)$ and $(b_1\,\cdots\,b_\ell)$ are **disjoint** if $a_i\ne b_j$ for all $i,j$.

**Note.**
- Disjoint cycles commute: $(a_1\,\cdots\,a_k)(b_1\,\cdots\,b_\ell)=(b_1\,\cdots\,b_\ell)(a_1\,\cdots\,a_k)$.
- Singletons act as the identity: $(a)=\operatorname{id}_X$ for any $a\in\{1,\dots,n\}$.

### Theorem 7.3 — Disjoint cycle decomposition

Every element $\sigma\in S_n$ can be written as a product of disjoint cycles. This expression is unique up to
1. shifting the elements in a cycle,
2. reordering the cycles,
3. suppressing singleton cycles.

E.g. $(1\,2)(1\,3\,2)=(1\,3)=(3\,1)=(3\,1)(2)$.

**Proof.** The action of $\langle\sigma\rangle$ on $X=\{1,\dots,n\}$ partitions $X$ into orbits,
$$X=\langle\sigma\rangle i_1\sqcup\langle\sigma\rangle i_2\sqcup\cdots\sqcup\langle\sigma\rangle i_\ell.$$
Set $k_j=|\langle\sigma\rangle i_j|$. Then
$$\sigma=\big(i_1\ \sigma(i_1)\ \cdots\ \sigma^{k_1-1}(i_1)\big)\cdots\big(i_\ell\ \sigma(i_\ell)\ \cdots\ \sigma^{k_\ell-1}(i_\ell)\big).$$
This proves existence. *Uniqueness?* The only choices were (i) the orbit representatives $i_j$, and (ii) the indexing of the orbits ($j\mapsto i_j$). Changing (i) shifts the elements of a cycle; changing (ii) permutes the cycles. Finally, we're free to omit singleton cycles, as they act as $\operatorname{id}_X$.

> [!note] Explanation
> Starting from $i_1$ and applying $\sigma$ repeatedly gives $i_1,\sigma(i_1),\sigma^2(i_1),\dots$; this runs through the orbit of $i_1$ and returns to $i_1$ after exactly $k_1$ steps (orbit–stabiliser for the cyclic group $\langle\sigma\rangle$). So on that orbit $\sigma$ acts as the cycle $(i_1\ \sigma(i_1)\ \cdots\ \sigma^{k_1-1}(i_1))$. Different orbits are disjoint, so the cycles are disjoint.

### Definition 7.4 — Cycle type

If $\sigma=(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)\cdots(a_1^\ell\,a_2^\ell\,\cdots\,a_{k_\ell}^\ell)$ is a product of disjoint cycles, then $\sigma$ is called a **$(k_1,\dots,k_\ell)$-cycle**. The multiset $\{k_1,k_2,\dots,k_\ell\}$ (repeats allowed) is called the **cycle type** of $\sigma$.

**Remark.**
- For a $k$-cycle $\sigma=(a_1\,\cdots\,a_k)$, $\operatorname{ord}(\sigma)=k$.
- If $\sigma$ is a $(k_1,\dots,k_\ell)$-cycle, $\operatorname{ord}(\sigma)=\operatorname{lcm}(k_1,\dots,k_\ell)$.

> [!note] Explanation
> The disjoint cycles commute, so $\sigma^m$ is the product of the $m$th powers of the cycles, and it is the identity exactly when each $k_j$-cycle's power is, i.e. when every $k_j$ divides $m$. The least such $m$ is $\operatorname{lcm}(k_1,\dots,k_\ell)$.

## 7.2 Transpositions

### Definition 7.5 — Transposition

A $2$-cycle is also called a **transposition**.

### Theorem 7.6 — Transpositions generate S_n

The set of transpositions generates $S_n$.

**Proof.** By induction on $n$.
- *Base case:* $n=2$, $S_2=\{e,(1\,2)\}$. ✓
- *Induction step:* suppose $S_{n-1}$ is generated by transpositions, and let $\sigma\in S_n$.
  - (a) If $\sigma(n)=n$, then $\sigma\in S_{n-1}\le S_n$, and $\sigma=\tau_1\cdots\tau_k$ for some $k$, with the $\tau_i$ transpositions.
  - (b) If $\sigma(n)\ne n$, let $\tau=(n\ \sigma(n))$. Now $(\tau\sigma)(n)=\tau(\sigma(n))=n$, so $\tau\sigma\in S_{n-1}\le S_n$. Hence $\tau\sigma=\tau_1\cdots\tau_k$ ($\tau_i$ transpositions), and so $\sigma=\tau\tau_1\cdots\tau_k$, as required.

> [!note] Explanation
> In (b), $\tau^{-1}=\tau$ (a transposition is its own inverse), so multiplying $\tau\sigma=\tau_1\cdots\tau_k$ on the left by $\tau$ gives $\sigma$. "$\sigma\in S_{n-1}$" means $\sigma$ fixes $n$ and so is a permutation of $\{1,\dots,n-1\}$.

### Definition 7.7 — Adjacent transposition

A transposition of the form $(i\ i{+}1)$ with $1\le i\le n-1$ is called **adjacent**.

### Lemma 7.8 — Adjacent transpositions suffice

Any transposition can be written as a product of adjacent transpositions.

**Proof.** Consider $(i\,j)$ and assume $j>i$; we argue by induction on $j-i$.
- *Base:* $j=i+1$, so $(i\,j)=(i\ i{+}1)$ is adjacent.
- *Inductive step:* assume $(i\ j{-}1)$ is a product of adjacent transpositions. Observe that
$$(i\,j)=(j{-}1\ j)(i\ j{-}1)(j{-}1\ j)$$
(by the conjugation formula, or just check by hand), and the result follows.

> [!note] Explanation
> By [[Groups - Chapter 3 Group Actions#Definition 3.10 — Conjugacy classes|Slogan #2]], $g(i\ j{-}1)g^{-1}$ with $g=(j{-}1\ j)=g^{-1}$ is the transposition $(g(i)\ g(j{-}1))=(i\,j)$. The right-hand side is a product of two adjacent transpositions and (by induction) a product of adjacent ones, so $(i\,j)$ is too. With Theorem 7.6, the adjacent transpositions generate $S_n$.

## 7.3 The sign of a permutation

Given $\sigma\in S_n$, consider its disjoint cycle decomposition **including all singletons**, and let $N(\sigma)$ be the number of cycles in it (well defined by Theorem 7.3). E.g. $\sigma=(1\,2\,3)(4\,5)\in S_7$ is $(1\,2\,3)(4\,5)(6)(7)$, so $N(\sigma)=4$.

### Lemma 7.9 — A transposition changes the number of cycles by one

Suppose $\sigma,\tau\in S_n$ with $\tau$ a transposition. Then $N(\tau\sigma)=N(\sigma)\pm1$.

**Proof.** Say $\tau=(b_1\,b_2)$ and the disjoint cycle decomposition of $\sigma$ (with singletons) is $\sigma=(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)\cdots(a_1^\ell\,\cdots\,a_{k_\ell}^\ell)$. Two cases.

*A) $b_1$ and $b_2$ are in the same cycle of $\sigma$*, say (after relabelling) $(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)$ with $b_1=a_1^1$, $b_2=a_i^1$. Then
$$(a_1^1\,a_i^1)(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)=(a_1^1\,a_2^1\,\cdots\,a_{i-1}^1)(a_i^1\,a_{i+1}^1\,\cdots\,a_{k_1}^1),$$
and the rest of the cycles of $\sigma$ are unchanged in $\tau\sigma$, so $N(\tau\sigma)=N(\sigma)+1$.

*B) $b_1$ and $b_2$ are in different cycles of $\sigma$*, say (after relabelling and reshuffling) $b_1=a_1^1$ and $b_2=a_1^2$. Then
$$(a_1^1\,a_1^2)(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)(a_1^2\,a_2^2\,\cdots\,a_{k_2}^2)=(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1\,a_1^2\,a_2^2\,\cdots\,a_{k_2}^2),$$
and the rest of the cycles of $\sigma$ are unchanged in $\tau\sigma$, so $N(\tau\sigma)=N(\sigma)-1$.

> [!note] Explanation
> Multiplying by a transposition either cuts one cycle into two (when both swapped points lie in the same cycle) or joins two cycles into one (when they lie in different cycles). Check case A from the right: $a_{i-1}^1\mapsto a_i^1\mapsto a_1^1$ closes the first new cycle, and $a_{k_1}^1\mapsto a_1^1\mapsto a_i^1$ closes the second.

### Theorem 7.10 — Sign homomorphism

The function
$$\operatorname{sign}:S_n\to C_2=\{\pm1\},\qquad\tau_1\tau_2\cdots\tau_k\mapsto(-1)^k,$$
where the $\tau_i$ are arbitrary transpositions, is a well-defined homomorphism.

**Proof.** *Well defined?* Say $\sigma=\tau_1\cdots\tau_k$ is some decomposition as a product of transpositions. By Lemma 7.9,
$$\begin{aligned}
N(\sigma)&\equiv N(\tau_1\cdots\tau_ke)\pmod2\\
&\equiv N(\tau_2\cdots\tau_ke)+1\pmod 2\\
&\ \ \vdots\\
&\equiv k+N(e)\pmod2.
\end{aligned}$$
So $k\equiv N(\sigma)+N(e)\pmod2$, and $k\bmod2$ is an invariant of $\sigma$.

*Homomorphism?*
$$\operatorname{sign}(\tau_1\cdots\tau_k\,\tau_1'\cdots\tau_\ell')=(-1)^{k+\ell}=(-1)^k(-1)^\ell=\operatorname{sign}(\tau_1\cdots\tau_k)\operatorname{sign}(\tau_1'\cdots\tau_\ell').$$

> [!note] Explanation
> Every $\sigma$ has many decompositions into transpositions, of different lengths, so "$(-1)^{\text{number of transpositions}}$" needs checking. Each transposition changes $N$ by $\pm1$, i.e. flips its parity, so the parity of $k$ is pinned down by $N(\sigma)$ and $N(e)=n$, which do not depend on the decomposition.

### Definition 7.11 — Even and odd permutations, alternating group

If $\operatorname{sign}(\sigma)=1$, $\sigma$ is called **even**; if $\operatorname{sign}(\sigma)=-1$, $\sigma$ is called **odd**. The subgroup
$$A_n=\ker(\operatorname{sign})\trianglelefteq S_n$$
is called the **alternating subgroup**. (Note $|S_n:A_n|=2$, as $\operatorname{sign}$ is onto for $n\ge2$.)

E.g. $S_3=\{e,(1\,2),(2\,3),(1\,3),(1\,2\,3),(1\,3\,2)\}$, so $A_3=\{e,(1\,2\,3),(1\,3\,2)\}\cong C_3$.

**Remarks.**
- $(a_1\,\cdots\,a_k)$ is even if and only if $k$ is odd.
- A $(k_1,\dots,k_\ell)$-cycle is even if and only if $\#\{i:k_i\text{ even}\}$ is even (it doesn't matter whether or not you include singletons).

E.g. $(1\,2)(3\,4)$ is even; $(1\,2)(3\,4)(5\,6)$ is odd.

> [!note] Explanation
> A $k$-cycle is a product of $k-1$ transpositions, $(a_1\,\cdots\,a_k)=(a_1\,a_k)\cdots(a_1\,a_2)$, so its sign is $(-1)^{k-1}$. A product of disjoint cycles then has sign $\prod_i(-1)^{k_i-1}$, which is $-1$ exactly when an odd number of the $k_i$ are even. Singletons have $k_i=1$, contributing $(-1)^0=1$.

### Lemma 7.12 — A_n is generated by 3-cycles

$A_n$ is generated by $3$-cycles.

**Proof.** Every element of $A_n$ is a product of an even number of transpositions, so $A_n$ is generated by products of $2$ transpositions. Now observe
$$(a\,b)(b\,c)=(a\,b\,c),\qquad(a\,b)(c\,d)=(a\,b\,c)(b\,c\,d),$$
so $3$-cycles generate.

> [!note] Explanation
> A product of two transpositions either shares a point, $(a\,b)(b\,c)$, or not, $(a\,b)(c\,d)$ (and $(a\,b)(a\,b)=e$). Both identities can be checked from the right; e.g. for the second, $a\mapsto a\mapsto b$, $b\mapsto c\mapsto a$, $c\mapsto d\mapsto d$, $d\mapsto b\mapsto c$. Each $3$-cycle is even, so it lies in $A_n$.

## 7.4 Conjugacy in S_n

### Theorem 7.13 — Conjugacy in S_n

Two permutations $\sigma_1,\sigma_2\in S_n$ are conjugate if and only if their cycle types are the same.

**Proof.** ($\Leftarrow$) Suppose
$$\sigma_1=(a_1^1\,a_2^1\,\cdots\,a_{k_1}^1)\cdots(a_1^\ell\,a_2^\ell\,\cdots\,a_{k_\ell}^\ell)$$
is a product of disjoint cycles, so $\sigma_1(a_i^j)=a_{i+1}^j$ (with $i+1$ taken mod $k_j$). As the cycle types are the same,
$$\sigma_2=(b_1^1\,b_2^1\,\cdots\,b_{k_1}^1)\cdots(b_1^\ell\,b_2^\ell\,\cdots\,b_{k_\ell}^\ell)$$
(disjoint cycles), with $\sigma_2(b_i^j)=b_{i+1}^j$. Now $\tau(a_i^j)=b_i^j$ defines a permutation of $\{1,\dots,n\}$. Compute:
$$\tau\sigma_1\tau^{-1}(b_i^j)=\tau\sigma_1(a_i^j)=\tau(a_{i+1}^j)=b_{i+1}^j=\sigma_2(b_i^j),$$
so $\tau\sigma_1\tau^{-1}=\sigma_2$.

($\Rightarrow$) Suppose $\sigma_2=\tau\sigma_1\tau^{-1}$. The computation above shows that if $\sigma_1=(a_1^1\,\cdots\,a_{k_1}^1)\cdots(a_1^\ell\,\cdots\,a_{k_\ell}^\ell)$, then $\sigma_2=(b_1^1\,\cdots\,b_{k_1}^1)\cdots(b_1^\ell\,\cdots\,b_{k_\ell}^\ell)$ where $b_i^j=\tau(a_i^j)$. Therefore $\sigma_1$ and $\sigma_2$ have the same cycle type.

Cf. the [[Groups - Chapter 3 Group Actions#Definition 3.10 — Conjugacy classes|action slogan]]: conjugate elements have the same "shape".

**Examples.**
- $|\operatorname{ccl}_{S_3}((1\,2))|=\binom32=3$.
- $|\operatorname{ccl}_{S_3}((1\,2\,3))|=2$.
- $|\operatorname{ccl}_{S_4}((1\,2)(3\,4))|=\frac12\binom42=3$.

> [!note] Explanation
> By the theorem, a conjugacy class is the set of all permutations of a given cycle type, so these are counting problems. A transposition in $S_3$ is fixed by choosing its $2$ points. A $3$-cycle on $\{1,2,3\}$ is $(1\,2\,3)$ or $(1\,3\,2)$. A $(2,2)$-cycle in $S_4$ is fixed by the pair containing $1$: choosing one of the $\binom42$ pairs and its complement counts each element twice.
